# Horseradish - Business Automation Website

A modern, post-modern light website inspired by Flow Digital's pricing page design, built for Horseradish business automation services.

## 🎨 Design Features

- **Post-modern light aesthetic** with clean, minimalist design
- **IBM Plex Sans font** for professional typography
- **Horseradish brand colors**:
  - Primary Blue: `#0092a2`
  - Primary Purple: `#c10078`
  - Secondary Blue: `#005bc0`
  - Orange: `#c55700`
  - Gold: `#cc8600`
  - Green: `#91c35c`
  - Dark: `#181a1b`

## 🚀 Features

### Navigation
- **Hamburger menu** for mobile devices
- **Fixed navigation bar** with backdrop blur effect
- **Smooth scrolling** to sections
- **CTA button**: "Schedule a Google Meet"

### Sections
1. **Hero Section** - Main headline with gradient text and geometric shapes
2. **Services** - Three service cards with icons
3. **Pricing** - Three pricing tiers (1-on-1 Session, Hourly Retainers, Fractional CAO)
4. **Testimonials** - Client feedback with star ratings
5. **CTA Section** - Call-to-action for scheduling meetings
6. **Footer** - Company information and social links

### Interactive Elements
- **Hover effects** on cards and buttons
- **Smooth animations** on scroll
- **Parallax effects** for geometric shapes
- **Ripple effects** on button clicks
- **Responsive design** for all devices

## 🛠️ Technologies Used

3. **Customize content** as needed for your business
4. **Deploy** to your web hosting service

## 🎨 Customization

### Colors
Update the CSS custom properties in `:root` to change the color scheme:

```css
:root {
    --primary-blue: #your-color;
    --primary-purple: #your-color;
    /* ... other colors */
}
```

### Content
- Update text content in `index.html`
- Modify service descriptions and pricing
- Add your own testimonials
- Update contact information

### Branding
- Replace "Horseradish" with your company name
- Update logo and branding elements
- Modify the CTA button text and links
