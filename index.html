                        01  What is a Host?
                        
    A someone with specialized knowledge. You plant it on a website, or zip it as an extension. It wakes on a qualifying event. It shares by code. Peer to peer.
    
                    
    
                    
    
                        02  What is the factory?
                        
    Horseradish codes Hosts. Walk in with a specialty. Design a body, feed it knowledge, tell it when to wake. Walk out with embed HTML or an extension ZIP.
    
                    
    
                    
    
                        03  How is this not a chatbot?
                        
    A chatbot waits in a bubble. A Host has a house: orchestrator, knowledge, peer to peer. It can live on a site as code, or off-site as an extension. It can stay quiet until the qualifying event.
    
                    
    
                    
    
                        04  What about Golda?
                        
    Golda is a Host already in the field. Antisemitism detection. Always-on. Off-site, as an extension. Share code HR-GOLDA. Proof. Not a sibling of the factory.
    
                    
    
                    
    
                        05  How do share codes work?
                        
    A Host swallows a code and inherits the specialty. HR-GOLDA wakes Golda. HR-HOUSE, HR-FLOOR, and HR-LISTING wake a restaurant, a storefront, and a real estate Host. Give the code to another Host. That is peer to peer.
    
                    
    
                    
    
                        06  Embed or ZIP?
                        
    Embed HTML plants the Host on a site. The ZIP is a Chrome extension you load unpacked. Same Host. Two residences.
    
                    
    
                    
    
                        07  Do I need to log in?
                        
    No. Copying and downloading do not require login. Saving to the Horseradish Host Factory floor does. This browser can keep a bench draft.
    
                    
    
                    
    
                        08  Is Horseradish an MCP?
                        
    Yes. That is the engine. The offering is the factory. MCP is how Horseradish codes a Host. It is not what you walk in for.
